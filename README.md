# Developer Universe

Personal portfolio website for Charan Raj, built with React 19 and Vite 8.

## Local development

Requirements: Node.js compatible with the installed Vite version and npm.

```sh
npm ci
npm run dev
```

## Checks and production build

```sh
npm run lint
npm run build
npm run preview
```

Vite writes the production site to `dist/`. The site is a static client-side React application.
